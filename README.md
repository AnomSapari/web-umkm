# NaikKelas UMKM

Website landing page untuk membantu UMKM mengubah profil online menjadi aset monetisasi: penawaran, katalog, WhatsApp funnel, dan paket mentoring.

## Cara menjalankan

Karena project ini dibuat sebagai website statis, cukup buka `index.html` di browser atau jalankan server lokal:

```bash
python3 -m http.server 4173
```

Lalu buka `http://localhost:4173`.

## Strategi monetisasi yang sudah disiapkan

1. **Jasa pembuatan landing page** — paket awal Rp799rb untuk validasi pasar cepat.
2. **Website katalog + funnel WhatsApp** — paket utama Rp1,9jt dengan margin lebih tinggi.
3. **Mentoring growth 30 hari** — produk premium Rp3,5jt untuk pendampingan dan retainer.
4. **Produk digital tambahan** — template konten, e-book closing, dan kelas mini untuk pendapatan pasif.
5. **Lead generation WhatsApp** — setiap tombol CTA membawa konteks paket agar admin lebih mudah follow-up.

## Checklist sebelum dipublikasikan

- Ganti nomor WhatsApp di `script.js` pada konstanta `WHATSAPP_NUMBER`.
- Ganti email footer di `index.html`.
- Tambahkan domain, Google Analytics, Meta Pixel, dan Google Search Console.
- Masukkan testimoni asli setelah mendapatkan klien pertama.
- Tambahkan halaman kebijakan privasi jika mulai menjalankan iklan berbayar.
